Líder Conecta

Aplicativo para ajudar líderes de equipes Natura e Avon a organizar consultoras e preparar campanhas promocionais.

Funcionalidades

- Painel de controle.
- Cadastro de consultoras.
- Criação de campanhas promocionais.
- Preparação de artes com imagens e textos.
- Seleção de destinatárias.
- Histórico demonstrativo de campanhas.

Tecnologias

- HTML
- CSS
- JavaScript
- GitHub
- Netlify

Status do projeto

Protótipo em desenvolvimento. O envio real de mensagens pelo WhatsApp e o armazenamento permanente dos dados ainda precisam ser configurados.

Publicação

O projeto poderá ser publicado pelo Netlify, conectado ao repositório do GitHub.
